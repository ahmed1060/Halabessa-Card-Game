These are renders of your actual Flutter screens using local fixtures, not redesign mockups. No uploads or cloud saves were performed.

  • Restore is not reliable yet. Same-slot uploads overwrite the same storage object, so a saved default URL can point to the new file too. Use immutable versions before relying on restore.
  • Built-in is not “No sound set.” Show Built-in, Saved default or Custom accurately; make factory reset and saved-default restore separate actions.
  • Preview should identify one row. Currently every SFX row shows a pause icon whenever any effect is playing.
  • Arabic needs a more flexible row. The current custom/default status overflows by 13 pixels at 390 px width and by up to 83 pixels at 320 px in the rendered fixtures.
  • Music needs a consistent fallback. Local home/room music share one ambience; online music with no remote URL currently waits instead of using that default.
  • Saving a clip should not rewrite match settings. The shared save method also writes the timer, target score and every loaded override.

Proposed order after selection: custom override → chosen saved default → bundled factory default. Keep the current offline/no-cloud boundary; downloaded offline overrides need an explicit cache policy.
